# Contract: web app

- Review → Goals & settings: "Attention thresholds" table (Threshold, Value with unit, Origin,
  Default, Meaning); a form with one number input per threshold bounded by its range; "Save
  thresholds" stores only values that differ from the inherited value or already have an
  override; "Reset all to defaults" button. The existing gap-days control is replaced by this
  form (same stored value).
- Tracker → settings area: "Installation thresholds" form with the same inputs and "Restore
  built-in defaults".
- Flags view: evidence sentences include the threshold. Adherence view states the threshold and
  origin.
